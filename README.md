# Workforce-participation-visualizer
Workforce Participation Visualizer is a C++ project that reads workforce data from CSV files and displays colorful ASCII charts to compare male and female participation rates. It helps visualize gender gaps using data analysis, file handling, and console-based graphical representation.The Workforce Participation Visualizer is a socially impactful C++ project designed to analyze and visualize workforce demographic data related to gender equality. The project focuses on identifying the participation levels of men and women across different employment sectors using CSV data processing and ASCII-based graphical representation. In many industries around the world, gender imbalance still exists. Some sectors have significantly higher male participation, while others have higher female participation. This project aims to represent such disparities in a simple, understandable, and visually engaging way using programming concepts. The system reads workforce statistics from a CSV file, processes the information, and generates colorful ASCII charts in the terminal window. These charts make it easier to compare gender participation percentages and observe workforce gaps instantly.
